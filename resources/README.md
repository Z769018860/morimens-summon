# 中文名称对照来源

`labels.zh-CN.json` 用于将 SKeyDB 的英文角色、命轮条目与抽卡通讯返回的中文名称对应。中文名称整理自[忘却前夜中文维基角色页](https://morimens.huijiwiki.com/wiki/分类:角色)和[命轮页](https://morimens.huijiwiki.com/wiki/命轮)；实体 ID 和英文名称参考 [SKeyDB](https://github.com/dansa/SKeyDB)。维基来源内容按其 CC BY-NC-SA 4.0 条款署名和非商业使用；游戏术语及游戏素材的权利仍归原权利人。

网页的 `web/catalog.json` 只存实体与图片地址的对应关系，图片由浏览器向 SKeyDB 的固定修订版本直接请求。桌面版首次运行可用 `sync_skeydb_assets.py` 建立本机缓存。图片文件不提交到本仓库；游戏图片的权利仍由原权利人持有。SKeyDB 的代码许可与游戏图片的权利范围不同，详见其[素材说明](https://github.com/dansa/SKeyDB/blob/master/ASSET-NOTICE.md)。
