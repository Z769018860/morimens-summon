使用教程

从下载本地工具、导出抽卡记录，到在网页上查看分析、参与欧非榜单——这一页把完整流程和隐私说明写清楚。

① 下载并运行本地导出工具

  1. 打开主页的「本地导出抽卡记录工具」卡片，点击「前往最新 Release」，下载最新的压缩包（Windows）。
  2. 解压到任意文件夹，保持游戏在前台登录状态，双击 start.cmd。首次运行会自动联网拉取角色/命轮图片素材（仅拉取公开的图片资源，不涉及你的账号）。
  3. 浏览器会自动打开 http://127.0.0.1:8765，这就是本地分析页面——注意网址是 127.0.0.1（你自己的电脑），不是任何外部网站。
  4. 点击右上角「↻ 自动更新」→「开始更新」。工具会读取当前这次游戏登录在内存里展示给你的抽卡历史并保存到本机数据库（data/local/history.sqlite3），每抓一页都会立即落盘。
  5. 如果提示「登录材料已释放」，点「等待重新登录」，然后重启一次游戏客户端，工具检测到新的登录后会自动继续读取。

导出记录

切到「抽卡记录」页，点击右上角「导出 JSON」或「导出 CSV」即可把当前记录保存为文件。建议先在「概率与规则」页填写昵称/UID（可选），这样分享图和榜单才能认出是谁的成绩。

② 在网页上查看数据分析

  1. 回到主页，点击「导入 JSON 查看数据分析」卡片。
  2. 把刚才导出的 .json 文件拖进去，或点击「选择文件」。
  3. 页面会自动跳转到和本地工具一样的分析页：总览、SSR 时间线、限时卡池日历、概率与规则、成就标签、分享图，功能完全一致。
  4. 这个过程全部在你的浏览器里完成：文件只会被 JavaScript 读进内存解析，不会上传到任何服务器，关闭标签页后就不留痕迹（除非你主动点了「导入」把一些设置写进浏览器本地存储）。

③ 参与欧非榜单

  1. 打开欧非榜单页面。
  2. 把你和朋友导出的 JSON 文件一起拖进去（可以多选）；每份文件会按「平均出货抽数」计算一行排名。
  3. 榜单数据保存在当前浏览器的本地存储（localStorage）里，不会同步到服务器或其他设备。想和朋友真正放在同一张榜单比较，请都在同一台电脑/同一个浏览器里依次导入大家的 JSON；或者各自在自己电脑上导入后，口头/截图分享名次。
  4. 随时可以在榜单页点「移除」删掉某一行，或「清空本机榜单」一次性清除。

④ 手动修正记录（可选）

自动判断「命中 UP / 歪」时，如果同一时间段有多个卡池重叠、或者数据不完整，工具会显示「无法确认」。这时你可以在「抽卡记录」页该条 SSR 右侧的下拉框里手动选择它实际命中的卡池，或选择「标记为无命中卡池」。

如果某条记录不是你想统计的抽卡结果（比如误把活动赠送记成抽卡、或者想单独排除某次样本），取消它左侧的「计入统计」勾选框即可——该条记录仍会显示在列表里（灰色），但不计入总览、成就标签和榜单统计。这些修正都只保存在你本机浏览器里，导出时会一并写进 JSON。

🔒 隐私与数据安全说明

本地工具会读取什么？

只会读取你自己账号当前这次游戏登录后，客户端展示给你看的抽卡历史记录（物品、时间、序号），用来整理统计。工具不记录、不上传、不传输账号密码、登录令牌、聊天内容、设备信息或任何其他游戏数据；所有抓取到的记录只写入你电脑本地的 data/local/history.sqlite3 文件。

导出的 JSON 里有什么？

只有抽卡记录本身（物品名称、稀有度、时间、序号、是否 UP）、你自愿手动填写的昵称/UID、以及基于这些记录算出的统计数字（成就标签、平均出货抽数等）。文件里没有任何能登录你账号的内容，分享给别人或上传到本网站做分析/榜单都不会危害账号安全。

网页版（分析页 / 榜单）会上传我的文件吗？

不会。导入 JSON 后，解析和展示全部在你的浏览器里用 JavaScript 完成；榜单数据存在浏览器的 localStorage 里，离开这台设备/浏览器就看不到了。本站没有后端数据库来接收或保存你上传的抽卡记录。

我还是不放心怎么办？

本地工具和网页前端都是开源的，可以在仓库里直接阅读源码确认上述说明；也可以断网之后再导入 JSON 查看分析页，验证确实不需要联网。
